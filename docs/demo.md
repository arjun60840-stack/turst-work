## 2. The 10-Minute Live Demo Script (Step-by-Step)

### ACT 1: Customer Posts a Group Hiring Request
1. Log in as `customer@nexvion.demo`
2. Tap **Create Job**
3. Select **Electrical** category
4. Select **Group Hiring** toggle $\rightarrow$ Set **Workers Needed: 4**
5. Enter Title: *"Community Solar & Wiring Overhaul"*
6. Set Budget: **₹5,000**
7. Tap **Find Best Candidates**

### ACT 2: Explainable AI Smart Matching
1. Screen transitions to **"Finding the best cooperative workforce..."**
2. System displays ranked cards. Top match: **Team Alpha (95% MATCH)**
3. Tap **"Why this match?"** to reveal the audit trail:
   - ✓ All required skills matched (*House Wiring, Solar Fitting*)
   - ✓ Team capacity verified (*4 of 4 workers available*)
   - ✓ Within transit radius (*2.8 km away*)
   - ✓ Verified Cooperative Status
   - ✓ 95% Platform Reliability
4. Tap **Book Team**
5. Review the **Digital Job Agreement** with upfront wage terms
6. Confirm Booking.

### ACT 3: Cooperative Accepts & Assigns Members
1. Log in as `cooperative@nexvion.demo`
2. View **Group Job Requests** $\rightarrow$ Accept Job
3. Review available roster $\rightarrow$ Assign 4 members (including Rahul Kumar)
4. Confirm Allocation.

### ACT 4: OTP + GPS On-Site Attendance
1. Customer displays on-site attendance code: **DEMO OTP: `123456`**
2. Worker logs in as `worker@nexvion.demo`
3. Worker opens active job $\rightarrow$ enters OTP `123456`
4. System validates location proximity $\rightarrow$ Marks Attendance
5. Job status automatically advances to **`IN_PROGRESS`**.
